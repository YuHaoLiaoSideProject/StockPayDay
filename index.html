📅 StockPayDay++

提醒投資人股利發放日期的工具。

✨ 功能

  • Crawler：從臺灣證券交易所（TWSE）抓取股利發放資料
  • Processor：處理原始資料、產生靜態 JSON API
  • Frontend：Vue 3 + Vite 靜態站台

🚀 立即使用

進入股票配息行事曆 →

📁 專案結構

StockPayDay++/
├── crawler/          # 資料爬蟲
├── processor/        # 資料處理
├── frontend/         # Vue 3 前端
├── data/             # 原始與處理後資料
├── api/              # 靜態 JSON API
└── docs/             # 專案文件

⚙️ 快速開始

後端

python -m venv venv
source venv/bin/activate
pip install -r requirements.txt

前端

cd frontend
npm install
npm run dev

🔄 自動部署

  • Push 到 master → 自動建構並部署至 GitHub Pages
  • 每日排程（UTC 08:00）→ 自動爬取最新資料
  • 手動觸發 → 可選擇是否執行爬蟲
