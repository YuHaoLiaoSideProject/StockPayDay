# Phase 2 測試計畫：爬蟲（MOPS）

## 📋 測試概覽

| 項目 | 內容 |
|------|------|
| **測試範圍** | MOPS 配息爬蟲 |
| **測試目標** | 驗證爬蟲可正確抓取配息日資料 |
| **測試環境** | 本機開發環境 |

---

## 🧪 測試案例

### TC-2.1：基本抓取功能

**目標**：驗證爬蟲可正常執行並取得資料

**前置條件**：
- 網路連線正常
- MOPS 網站可正常訪問

**步驟**：
1. 執行 `python crawler/fetch.py`
2. 檢查執行過程無錯誤

**預期結果**：
- 執行完成無紅色錯誤
- 執行時間 < 60 秒

---

### TC-2.2：資料格式驗證

**目標**：驗證儲存的資料格式正確

**前置條件**：
- TC-2.1 通過

**步驟**：
1. 檢查 `data/mops/` 目錄
2. 開啟最新的 JSON 檔案
3. 驗證欄位格式

**預期結果**：
- 檔案存在且為有效 JSON
- 每筆資料包含：code, ex_date, pay_date
- ex_date 格式為 YYYY-MM-DD
- pay_date 格式為 YYYY-MM-DD

---

### TC-2.3：重複執行去重

**目標**：驗證重複執行不會產生重複資料

**前置條件**：
- TC-2.2 通過

**步驟**：
1. 記錄目前資料筆數
2. 執行 `python crawler/fetch.py`
3. 比較資料筆數

**預期結果**：
- 資料筆數不變（或僅新增）
- 無重複的 (code, ex_date) 組合

---

### TC-2.4：日期轉換驗證

**目標**：驗證民國年日期正確轉換為西元年

**前置條件**：
- TC-2.1 通過

**步驟**：
1. 檢查 JSON 檔案中的日期
2. 驗證民國年已轉換為西元年

**預期結果**：
- 所有日期格式為 YYYY-MM-DD
- 無民國年格式（如 115年08月21日）

---

### TC-2.5：錯誤處理驗證

**目標**：驗證網路失敗時有適當處理

**前置條件**：
- 可模擬網路斷線（如關閉網路）

**步驟**：
1. 模擬網路斷線
2. 執行爬蟲
3. 檢查錯誤訊息

**預期結果**：
- 有重試機制（3 次）
- 有錯誤日誌記錄
- 不會崩潰
