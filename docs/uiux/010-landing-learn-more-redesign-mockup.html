010 — Landing「了解更多」流程重設計

BEFORE / AFTER 比較稿 ・ LandingView 「了解更多 ↓」按鈕 + How It Works 區塊

1️⃣ 問題根因

Vue Router hash mode 下，錨點連結被解釋為路由路徑，導致空白頁。

1P1 空白頁 — <a href="#how-it-works"> 在 hash mode 下被 Vue Router 攔截，解釋為路由 /how-it-works（不存在）→ 空白頁
2Footer 同樣問題 — Footer 的「功能介紹」連結 href="#how-it-works" 同樣會進入空白頁
3How It Works 區塊設計單薄 — 僅有 3 個圓形數字 + 文字，無視覺輔助，用戶難以快速理解產品價值
4CTA 與「了解更多」缺少層次 — 兩個按鈕並排但視覺權重相同，用戶不知該先做什麼

2️⃣ BEFORE / AFTER 比較

左側為現狀（P1 bug + 設計問題），右側為目標設計。

5️⃣ 實作方案 — 修復錨點滾動

推薦方案 A：使用 @click.prevent + scrollIntoView。

LandingView.vue — template 修改
- <a href="#how-it-works" class="landing-btn landing-btn-secondary">
+ <a href="#how-it-works"
+    class="landing-btn landing-btn-secondary"
+    @click.prevent="scrollToSection('how-it-works')">
     了解更多 ↓
   </a>
LandingView.vue — script 新增
+ function scrollToSection(id: string) {
+   document.getElementById(id)?.scrollIntoView({ behavior: 'smooth' })
+ }
Footer 連結同步修改
- <a href="#how-it-works">功能介紹</a>
+ <a href="#how-it-works"
+    @click.prevent="scrollToSection('how-it-works')">功能介紹</a>
備註：此方案保留 href="#how-it-works" 以維持 URL 可分享性（使用者可手動輸入 /##/how-it-works），同時透過 @click.prevent 阻止瀏覽器預設行為，改用 JS 控制滾動。
