2️⃣ BEFORE / AFTER 比較

左側為現行設計（BEFORE），右側為重設計（AFTER）。互動切換深色/裝置模式觀察兩者差異。

BEFORE 現行 Header

AFTER 重設計 Header

StockPayDay++
高度 48px · Logo 左 padding 4px · 按鈕間距 8px · z-index 50 · aria-pressed ✅
  • 📐 高度 56px → 48px（desktop）：減少 8px，釋放更多內容空間；mobile 維持 56px 以符合觸控目標
  • 🧭 Logo 區域增加 left padding：從 0 改為 4px，與 header-left 內部元素形成視覺分組
  • ↔️ 圖示按鈕間距 4px → 8px：降低誤觸機率，提升 Fitts' Law 達標效率
  • 🔝 SearchBar z-index 40 → 50：確保搜尋下拉選單不會被其他 z-index 層遮蔽
  • ♿ Theme toggle 增加 aria-pressed：無障礙螢幕閱讀器可感知目前主題狀態
  • 📱 Mobile logo 增加 title tooltip：隱藏文字時仍提供完整名稱提示

4️⃣ 完整畫面 — Mobile

Mobile 模式下 Header 行為：Logo 文字隱藏、搜尋欄全屏展開、觸碰目標 ≥ 44px。

StockPayDay++
Mobile 規範：
① Header 高度維持 56px（符合 WCAG 2.5.5 觸碰目標 ≥ 44px）
② Logo 文字隱藏（.logo-text { display: none }），增加 title="StockPayDay++" tooltip
③ 圖示按鈕放大至 44×44px（原始 40px）以符合觸控標準
④ SearchBar 點擊後全屏展開：width: 100vw; top: 56px; z-index: 50
⑤ 輸入框放大至 44px height / 1rem font-size，方便觸控輸入
