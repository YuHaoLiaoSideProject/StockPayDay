## 2. 設計原則

| # | 原則 | 說明 |
|---|------|------|
| 1 | **一致性** | 追蹤按鈕在所有位置保持相同的視覺語言（❤️ 圖示、紅色系） |
| 2 | **漸進式揭露** | 空狀態顯示引導，有內容後顯示行事曆/列表 |
| 3 | **Contextual 不佔位** | 追蹤按鈕嵌入既有元件，不額外佔用空間 |
| 4 | **語意化圖示** | ❤️ 代表追蹤、🔍 代表搜尋、📋 代表列表 |
| 5 | **即時回饋** | 點擊追蹤按鈕後立即更新視覺狀態 + 徽章數字 |

## 5. 狀態矩陣

### 5.1 追蹤按鈕狀態

| 狀態 | 視覺 | 互動 | 備註 |
|------|------|------|------|
| **未追蹤 (idle)** | 空心 ♡，灰色 `var(--heart-default)` | hover 變色 | 預設狀態 |
| **未追蹤 (hover)** | 空心 ♡，淺紅 `var(--heart-hover)` | 準備點擊 | 視覺回饋 |
| **未追蹤 (focus)** | 空心 ♡，蓝色 ring | 鍵盤可操作 | 無障礙 |
| **未追蹤 (active)** | 按下縮放 scale(0.95) | 點擊加入追蹤 | 即時回饋 |
| **已追蹤 (idle)** | 實心 ♥，紅色 `var(--heart-active)` | hover 變色 | 已加入狀態 |
| **已追蹤 (hover)** | 實心 ♥，深紅 | 準備點擊移除 | 視覺回饋 |
| **已追蹤 (focus)** | 實心 ♥，蓝色 ring | 鍵盤可操作 | 無障礙 |
| **已追蹤 (active)** | 按下縮放 scale(0.95) | 點擊移除追蹤 | 即時回饋 |
| **disabled** | 空心 ♡，opacity: 0.5 | 不可點擊 | 載入中或錯誤時 |
| **loading** | spinner 動畫 | 不可點擊 | 正在處理中 |

### 5.2 搜尋欄狀態

| 狀態 | 視覺 | 互動 | 備註 |
|------|------|------|------|
| **idle** | 灰色邊框，placeholder 顯示 | 可點擊輸入 | 預設狀態 |
| **focus** | 藍色邊框 `var(--search-focus)` | 準備輸入 | 無障礙 |
| **has-value** | 顯示 clear 按鈕 (✕) | 可清除輸入 | - |
| **has-results** | 下拉列表顯示 | 可選擇結果 | z-index: 50 |
| **no-results** | 下拉顯示「找不到符合的證券」 | 可修改關鍵字 | - |
| **loading** | input 右側 spinner | 等待搜尋結果 | - |
| **disabled** | opacity: 0.5 | 不可點擊 | 載入索引時 |

### 5.3 追蹤清單頁面狀態

| 狀態 | 視覺 | 互動 |
|------|------|------|
| **empty** | 空狀態引導畫面 | 搜尋或導航 |
| **has-items (calendar)** | 行事曆 + 追蹤標記 | 切換模式、點擊日期 |
| **has-items (list)** | 列表 + 追蹤按鈕 | 切換模式、點擊股票 |
| **loading** | spinner | 等待載入 |
| **error** | 錯誤訊息 + 重試按鈕 | 點擊重試 |

## 7. 無障礙清單

| WCAG 準則 | 要求 | 實作方式 |
|-----------|------|---------|
| 1.4.1 | 不以顏色單獨傳達 | 追蹤狀態用圖示（♥/♡）+ 顏色雙重表達 |
| 2.5.5 | 觸控目標 ≥ 40px | 按鈕最小 24px + padding 達 44px |
| 2.4.7 | Focus ring 可見 | 所有按鈕有 `focus:ring-2 focus:ring-accent` |
| 4.1.2 | ARIA 狀態 | `aria-label="加入追蹤"` / `aria-label="移除追蹤"` |
| 4.1.2 | ARIA pressed | `aria-pressed="true/false"` 表達追蹤狀態 |

### 鍵盤操作

| 按鍵 | 行為 |
|------|------|
| `Tab` | 在追蹤按鈕、搜尋欄、模式切換間移動焦點 |
| `Enter` / `Space` | 觸發追蹤按鈕、選擇搜尋結果 |
| `Escape` | 關閉搜尋結果下拉 |
| `Arrow Down/Up` | 在搜尋結果中移動 |

## 8. 實作建議

### 8.1 元件結構

```
WatchlistButton.vue
├── <button> (aria-pressed, aria-label)
│   ├── <svg> (未追蹤: 空心愛心)
│   └── <svg> (已追蹤: 實心愛心)
└── CSS (尺寸、顏色、動畫)

WatchlistView.vue
├── <div class="watchlist-header">
│   ├── <h1> 標題
│   └── <SearchBar> 搜尋欄
├── <div class="watchlist-empty"> (v-if="empty")
│   └── 空狀態引導
└── <div class="watchlist-content"> (v-else)
    ├── <ViewSwitcher> 模式切換
    ├── <Calendar> (v-if="calendar")
    └── <ListView> (v-else)
```

### 8.2 CSS 策略

```css
/* 追蹤按鈕 */
.watchlist-btn {
  @apply flex items-center justify-center rounded-full
         transition-all duration-150 ease-in-out;
}

.watchlist-btn--sm { @apply w-6 h-6 p-[10px]; }
.watchlist-btn--md { @apply w-8 h-8 p-[6px]; }
.watchlist-btn--lg { @apply w-10 h-10 p-[2px]; }

.watchlist-btn:not(.watched) {
  @apply text-[var(--heart-default)] hover:text-[var(--heart-hover)];
}

.watchlist-btn.watched {
  @apply text-[var(--heart-active)] hover:text-[var(--heart-hover)];
}

.watchlist-btn:active {
  @apply scale-95;
}

.watchlist-btn:focus-visible {
  @apply ring-2 ring-[var(--search-focus)] ring-offset-2;
}

/* 追蹤徽章 */
.watchlist-badge {
  @apply px-1.5 py-0.5 text-[var(--fs-badge)]
         bg-[var(--badge-bg)] text-[var(--badge-text)]
         rounded-full min-w-[var(--badge-size)];
}

/* 行事曆追蹤圓點 */
.calendar-day .watched-dot {
  @apply absolute bottom-1 right-1 w-2 h-2
         bg-[var(--watched-dot)] rounded-full;
}
```

### 8.3 動畫細節

| 動畫 | 屬性 | 說明 |
|------|------|------|
| 追蹤按鈕切換 | `transform`, `color` | 150ms ease，scale(0.95) → scale(1) |
| 徽章數字更新 | `opacity` | 300ms fade，數字淡出 → 新數字淡入 |
| 搜尋結果下拉 | `opacity`, `transform` | 200ms ease，translateY(-8px) → translateY(0) |
| 行事曆追蹤標記 | `opacity` | 150ms fade，新追蹤立即顯示 |

### 8.4 `prefers-reduced-motion`

```css
@media (prefers-reduced-motion: reduce) {
  .watchlist-btn,
  .watchlist-badge,
  .search-results {
    transition: none;
  }
  .watchlist-btn:active {
    transform: none;
  }
}
```
