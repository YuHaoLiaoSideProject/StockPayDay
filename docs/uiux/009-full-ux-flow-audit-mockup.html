♿ 9. 無障礙（WCAG）審計

逐條 WCAG 準則檢查，標註通過/部分通過/未通過。

WCAG 準則狀態說明
1.3.1 Info & Relationships部分通過ViewSwitcher role=tablist ✓ · SearchBar role=combobox ✓ · CalendarDay 無 role=button（div+@click）
1.4.1 Use of Color通過追蹤/非追蹤不只靠顏色，有 ♥ 符號 + 背景色差異
1.4.3 Contrast (Min)通過--text-muted: #6b7280 對白底 ≈4.7:1 ✓
2.1.1 Keyboard部分通過Modal focus trap ✓ · ViewSwitcher Tab ✓ · CalendarDay div+@click 無 tabindex
2.4.7 Focus Visible通過所有互動元素有 :focus-visible 樣式（box-shadow ring）
2.5.5 Target Size部分通過Header icon 44px ✓ · WatchlistButton--sm 32px、WatchlistItemRow 內愛心 32px
4.1.2 Name, Role, Value通過SearchBar aria-expanded ✓ · WatchlistButton aria-pressed ✓ · Modal aria-modal ✓
重點：CalendarDay 的鍵盤可操作性是最高優先無障礙問題（WCAG 2.1.1 + 1.3.1）。建議將 .calendar-day 改為 <button> 或加 tabindex="0" + role="gridcell" + @keydown.enter。
