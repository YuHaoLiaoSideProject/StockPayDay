4️⃣ 實作指引 — 需要修改的檔案

移除 Features 區塊的具體修改位置。

檔案修改內容
frontend/src/views/LandingView.vue 移除 <section id="features" class="features">...</section> 整個區塊（約 40 行）
frontend/src/views/LandingView.vue Hero 中「了解更多 ↓」按鈕的 href="#features" 改為 href="#how-it-works"，並在 How It Works section 加上 id="how-it-works"
frontend/src/style.css 可保留 `.features` 樣式（供未來使用），或清理相關 CSS（約 40 行）
frontend/src/views/LandingView.vue Footer 中「功能介紹」連結改為指向 #how-it-works 或移除
影響範圍：僅 LandingView.vue + 可選 style.css。不影響 app 功能、路由、或其他頁面。
