設計重點說明

1
Hero Section — 以用戶利益為核心的價值主張，取代 README 風格的技術描述。漸層背景增加視覺層次。
2
Social Proof — 「已追蹤超過 2,000 支股票」建立信任感，星號圖示增加視覺吸引力。
3
Feature Cards — 三欄卡片佈局，hover 效果增加互動感。每個功能回答「這對你有什麼好處」。
4
How It Works — 三步驟流程圖，降低使用門檻認知。圓圈 + 箭頭視覺引導。
5
CTA Section — 底部再次呼籲行動，大按鈕 + 補充文字（免費、無需註冊）降低決策阻力。
6
Footer — 深色背景 footer，品牌 + 連結 + 版權，建立專業形象。
7
RWD — Mobile: Hero 縮小、CTA 全寬、Features 改横排卡片、Steps 縱排。所有觸控目標 ≥ 44px。
8
Theme — 完整 Light/Dark 雙主題，所有色彩使用 CSS 變數，無硬編碼色值。
