## 概述

讓使用者在**搜尋結果下拉中直接點擊 ❤️ 加入追蹤**（不需跳頁），並在**追蹤清單頁頂部提供常駐搜尋欄**，支援追蹤「尚未公布配息」與「已下市」的股票；全部為純前端改良，後端／爬蟲／processor 零變更。核心包含：

1. **SearchBar 具名 Slot `#result-actions`**：結果列右側注入 ❤️，SearchBar 保持與 watchlist 領域完全解耦（Tech Decision 001）。
2. **WatchlistButton 防誤導航強化**：內建 `@mousedown.stop.prevent`（配合既有 `@click.stop`），點 ❤️ 不觸發列導航、不關閉下拉（Tech Decision 006）。
3. **追蹤清單頁常駐搜尋欄**：`views/WatchlistView.vue` 標題下方新增獨立 SearchBar，空狀態時亦可用（Tech Decision 002）。
4. **無配息顯示沿用**：`components/WatchlistView.vue` 的 `allWatchedItems`（items 為主、upcoming 為補）已於 009 實作，本功能不改動，僅補驗證（Tech Decision 002）。
5. **type 保守預設 `'stock'`**：所有新增呼叫點統一傳入 `'stock'`，不依資料源猜測（Tech Decision 003）。
6. **localStorage 降級沿用 + 補測試**：既有的 init()／watchEffect try/catch 不動，補 setItem/getItem 拋錯的單元測試（Tech Decision 004）。
7. **手機版觸控目標**：搜尋列 ❤️ 用 `size="sm"`，mobile 覆寫至 44×44px；追蹤清單頁搜尋欄頁面常駐、不套 header 收合（Tech Decision 005）。

### 2.2 useWatchlist / useSearch（既有 composable：runtime 零變動）

**useWatchlist**：本功能只「新增呼叫點」，不改其行為。既有保證（程式碼已驗證）即本功能的持久化規格：

- **module-level singleton**：`items` / `sortBy` 為模組級 `ref`，跨頁面（導覽列、追蹤清單頁、詳情頁）狀態一致 → 對應 BDD #17。
- **`init()` try/catch 讀取** + **`watchEffect` try/catch 寫入**（key: `stockpayday-watchlist`）→ localStorage 不可用時僅 session 記憶、不 crash → 對應 BDD #21。
- **`add` / `toggle` 型別預設 `type: 'stock'`、無數量上限** → 對應 Tech Decision 003、BDD #24。
- **`remove` 僅依 code 過濾**：不依 upcoming 存在與否過濾，已下市股票自然保留 → 對應 BDD #14。

```typescript
// frontend/src/composables/useWatchlist.ts（現況 = 規格，本功能不改）
const STORAGE_KEY = 'stockpayday-watchlist'
const items = ref<WatchlistItem[]>([])              // module-level singleton
const sortBy = ref<WatchlistSortBy>('addedAt')

function init(): void { /* try { localStorage.getItem } catch { 空清單 } */ }
watchEffect(() => { /* try { localStorage.setItem } catch { 不持久，session 記憶 } */ })

export function useWatchlist() {
  function add(code: string, name: string, type: WatchlistItem['type'] = 'stock'): void
  function remove(code: string): void
  function toggle(code: string, name: string, type: WatchlistItem['type'] = 'stock'): void
  function isWatched(code: string): boolean
  const watchedCodes = computed(() => new Set(items.value.map(i => i.code)))
  // return: items, sortBy, sortedItems, watchedCodes, add, remove, toggle, isWatched, clear, reset
}
```

**useSearch**：本功能不改；`query` 觸發 `results` 即時計算（代號/名稱模糊匹配、忽略大小寫、`slice(0, 10)` 上限 10 筆）。追蹤清單頁獨立 new 一份實例（各自的 query/results），與導覽列互不干擾。

```typescript
// frontend/src/composables/useSearch.ts（現況 = 規格，本功能不改）
export function useSearch() {
  const query = ref('')
  const securitiesIndex = ref<SecurityIndex[]>([])   // fetch('./api/securities-index.json')
  const indexLoaded = ref(false)
  const results = computed(() => {
    if (!query.value.trim()) return []               // 搜尋欄為空 → 不顯示下拉（BDD #20）
    const q = query.value.trim().toLowerCase()
    return securitiesIndex.value
      .filter(s => s.code.toLowerCase().includes(q) || s.name.toLowerCase().includes(q))
      .slice(0, 10)                                   // 最多 10 筆（BDD #23）
  })
  return { query, results, indexLoaded, retryLoadIndex }
}
```

### 2.4 WatchlistButton.vue：內建 `@mousedown.stop.prevent`

**職責**：一次改動保護所有使用點（詳情頁 `size="lg"`、追蹤列 `size="sm"`、搜尋結果列 `size="sm"`），防止 ❤️ 上的 mousedown 冒泡到「結果列」的 `@mousedown.prevent` 導航 handler。

**事件防護流程（Tech Decision 006）**：
```
使用者點擊搜尋結果的 ❤️
  ├─ mousedown → WatchlistButton @mousedown.stop.prevent（新增）
  │     ├─ .stop → 不冒泡到列的 @mousedown.prevent → 不導航 ✅
  │     └─ .prevent → 阻擋 mousedown 預設「按鈕搶焦」，input 不失焦 → 下拉保持顯示 ✅
  ├─ click → WatchlistButton @click.stop（既有）
  │     └─ 不冒泡 → 不導航 ✅
  └─ 結果：僅 toggle 追蹤；徽章 ±1（useWatchlist singleton 自動響應）
```

> **為何需要 `.prevent`**：若僅 `.stop` 不 `.prevent`，mousedown 的預設行為仍會把 focus 移到按鈕上 → input `blur` → `setTimeout(150ms)` 後下拉關閉，違反「點 ❤️ 後下拉保持顯示」（BDD #3/#4，兩者皆為點 ❤️ 且下拉須保持顯示；IF 005）。`.prevent` 阻止預設搶焦，focus 留在 input；E2E 以 `waitForTimeout(400)` 跨過 blur 窗口實測驗證。

```vue
<!-- frontend/src/components/WatchlistButton.vue（改動後：根元素新增一列） -->
<script setup lang="ts">
interface Props {
  code: string
  name: string
  type?: 'stock' | 'etf' | 'preferred'   // 呼叫端一律傳 'stock'（Tech Decision 003）
  size?: 'sm' | 'md' | 'lg'
}
const props = withDefaults(defineProps<Props>(), { type: 'stock', size: 'md' })
const { isWatched, toggle: toggleWatchlist } = useWatchlist()
const watched = computed(() => isWatched(props.code))
function handleClick() {
  const wasWatched = watched.value
  toggleWatchlist(props.code, props.name, props.type)   // 預設 type='stock'
  emit('toggle', props.code, !wasWatched)
}
</script>

<template>
  <button
    :class="['watchlist-btn', sizeClass, { watched }]"
    :data-testid="`heart-${props.code}`"  <!-- 新增：E2E/元件測試錨點（heart-{code}） -->
    :aria-label="watched ? '移除追蹤' : '加入追蹤'"
    :aria-pressed="watched"
    @click.stop="handleClick"
    @mousedown.stop.prevent  <!-- 新增：.stop 擋冒泡（不觸發列導航）；.prevent 擋搶焦（防 input blur 關閉下拉） -->
  >
    <svg v-if="watched" ... />   <!-- 實心 ❤️（watchlist-btn.watched） -->
    <svg v-else ... />           <!-- 空心 ♡（watchlist-btn:not(.watched)） -->
  </button>
</template>
```

### 2.6 追蹤清單無配息顯示（沿用 009，本功能不動）

`components/WatchlistView.vue` 的 `allWatchedItems`（Tech Decision 002 已實作）即本功能的無配息規格：**items 為主、upcoming 為補** → 無論股票是否在 `upcoming.json`，一律渲染；配息僅作為附加屬性。`WatchlistItemRow` 在 `dividend` 為 undefined 時顯示「無近期配息」（`.item-no-dividend`）。本功能不改此區塊，只補「新加入路徑（搜尋結果 ❤️）」的驗證（E2E #1.8）。

```typescript
// frontend/src/components/WatchlistView.vue（009 既有 = 規格）
const allWatchedItems = computed(() => {
  return items.value.map(item => {
    const dividend = upcoming.value.find(u => u.code === item.code)  // UpcomingDividend | undefined
    return { ...item, dividend, hasUpcomingDividend: !!dividend }
  })
})
// watchlistUpcoming（有配息者）→ 行事曆日期標記
// sortedAllItems（全部追蹤項目）→ WatchlistItemRow：dividend 有 → 金額；無 → 「無近期配息」
```

### 2.7 type 判定（Tech Decision 003）

- `upcoming.json` 的 `type`（「息／權息／權」）是**配息形式**，非證券類型；`securities-index.json` 無 type 欄位 → 兩者皆不可信，一律保守預設 `'stock'`。
- 所有新增呼叫點（App.vue 導覽列 slot、追蹤清單頁 slot）與既有詳情頁統一以 `'stock'` 傳入 `WatchlistButton`；`useWatchlist.add/toggle` 預設值即為 `'stock'`，零成本。
- 目前 UI（WatchlistItemRow）不顯示 type，無可見影響。

```
                                                  ▼
┌────────────── api/upcoming.json ──────────────┐    components/WatchlistView
│  （useUpcoming 既有；重載頁面才更新）               │    allWatchedItems = items.map({ ...item, dividend, hasUpcomingDividend })
└───────────────────────┬────────────────────────┘
                        ▼ find(u => u.code === item.code)
        dividend 存在 → WatchlistItemRow 顯示配息金額 💰
        dividend 不存在 → WatchlistItemRow 顯示「無近期配息」✅（含已下市股票）
        徽章：items.length（App.vue .watchlist-badge，singleton 自動 ±1）
```

**同步／非同步性質**：
- 追蹤操作（toggle → items → localStorage）為同步反應式更新，徽章與追蹤清單立即響應（BDD #10、#17）。
- `securities-index.json`／`upcoming.json` 為 async fetch；觸發於 composable 建構時（useSearch、useUpcoming），non-blocking。
- 配息資料需**重新載入頁面**才更新（BDD #15：`upcoming.json` 更新後重載）。

## 6. 邊界條件處理

| 情境 | 來源 | 處理方式 |
|------|------|---------|
| 搜尋欄為空 | BDD @edge-case #20 | `useSearch.results` 對空 query 回傳 `[]`，SearchBar `v-if="results.length > 0"` 不渲染下拉（既有邏輯，補測試） |
| localStorage 不可用（隱私模式） | BDD @edge-case #21、IF 異常-3、TD 004 | `init()`（getItem）與 `watchEffect`（setItem）既有 try/catch：操作正常（❤️ 實心、徽章 +1）、僅不持久、無額外 UI 提示；補單元測試鎖定（mock setItem/getItem throw） |
| 已下市股票 | BDD @edge-case #14、IF 異常-4、TD 002 | `allWatchedItems` 以 items 為主不過濾 → 仍顯示；`upcoming.find` 回 undefined → 顯示「無近期配息」；由使用者手動移除 |
| 追蹤清單為空時搜尋 | BDD @edge-case #11 | 追蹤清單頁搜尋欄在 `WatchlistEmpty` 上方的頁面層常駐，空狀態下仍可輸入並加入（加入後清單立即更新，脫離空狀態） |
| 追蹤清單頁搜尋無結果 | BDD @edge-case #12 | SearchBar 既有 `no-results` 區塊顯示「找不到符合的證券」 |
| 點擊外部／Escape 關閉下拉 | BDD @edge-case #22、IF 異常-5 | SearchBar 既有 `@blur` + `setTimeout(150ms)` 與 `onKeydown` Escape（已加入的追蹤狀態保持，不清空） |
| 搜尋結果最多 10 筆 | BDD @edge-case #23、IF 邊界-3 | `useSearch.results` 既有 `slice(0, 10)`；每筆仍含 ❤️ |
| 追蹤數量無硬性上限 | BDD @edge-case #24、IF 邊界-1 | `useWatchlist.add` 無上限（建議 ≤100）；第 101 支正常加入、無提示；補單元測試 |
| 多裝置各自獨立 | BDD @edge-case #25、IF 邊界-2 | localStorage key（`stockpayday-watchlist`）裝置本地，無同步機制；天然多裝置獨立 |
| type 判定資料源不足 | TD 003（取捨） | 保守預設 `'stock'`；不從 `upcoming.type`（息/權息/權）或 index 猜測，寧缺勿錯 |
| 點 ❤️ 誤觸發導航（mousedown 冒泡） | TD 006（取捨）、風險登錄 | WatchlistButton 內建 `@mousedown.stop.prevent`（.stop 擋冒泡、.prevent 防搶焦關閉下拉）+ `@click.stop`；列 `@mousedown.prevent` 不變；E2E 斷言「下拉保持顯示、URL 不變」 |
| 追蹤清單頁／導覽列兩份 useSearch 重複載入 index | TD 風險登錄 | 瀏覽器 HTTP 快取緩解；已知行為，不處理（useSearch 模組級 singleton 列為衍生工作） |
| 結果列 mobile 觸控目標 < 44px | TD 005（取捨） | `@media (max-width:767px)` 覆寫 `.search-result-item .watchlist-btn--sm` 至 44×44px；desktop 不變 |
