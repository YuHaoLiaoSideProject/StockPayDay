| 項目 | 內容 |
|------|------|
| **最終方案** | 靜態站 + GitHub Actions + 爬蟲分層架構 |
| **決策日期** | 2026-07-21 |
| **共識程度** | ✅ 確認通過 |

---

## 1. 需求回顧

### 核心需求
- **使用者**：小群體分享
- **資料範圍**：台股全部配息證券（個股、ETF、特別股、債券 ETF）
- **資料來源**：統一從 TWSE 抓取
- **顯示模式**：行事曆 / 列表切換
- **資料保留**：爬蟲端持久化，前端不顯示原始資料
- **歷史查詢**：可查詢單一證券配息歷史
- **通知**：配息前提醒
- **部署方式**：GitHub Actions + GitHub Pages

### 關鍵決策
1. 不區分證券類型（股票、ETF、特別股統一顯示）
2. 資料分層：`data/`（基底）→ `processor/` → `api/`（前端用）
3. 每支證券獨立檔案，方便查詢歷史

---

## 2. 候選方案評估

| 方案 | 描述 | 結果 |
|------|------|------|
| 🟢 靜態站 + GitHub Actions | 爬蟲 + JSON + GitHub Pages | ✅ **採用** |
| 🟡 Serverless + Supabase | 爬蟲 + PostgreSQL + Vercel | ❌ 過度設計 |
| 🔵 全端框架 | FastAPI + SQLite | ❌ 維運成本高 |

### 選擇理由
1. **配息資料更新頻率低** — 每天跑一次 GitHub Actions 足夠
2. **小群體使用** — GitHub Pages 免費方案綽綽有餘
3. **零維運** — 不用管伺服器、資料庫
4. **資料結構簡單** — JSON 完全夠用

## 6. GitHub Actions 工作流程

```yaml
name: Update Dividend Data

on:
  schedule:
    - cron: '0 8 * * *'  # 每天 UTC 08:00 (台北 16:00)
  workflow_dispatch:  # 手動觸發

jobs:
  update:
    runs-on: ubuntu-latest
    steps:
      - name: Checkout
        uses: actions/checkout@v4

      - name: Setup Python
        uses: actions/setup-python@v5
        with:
          python-version: '3.11'

      - name: Install dependencies
        run: pip install -r crawler/requirements.txt

      - name: Run crawler
        run: python crawler/fetch.py

      - name: Run processor
        run: python processor/generate_api.py

      - name: Notify
        if: success()
        run: python processor/notify.py
        env:
          LINE_NOTIFY_TOKEN: ${{ secrets.LINE_NOTIFY_TOKEN }}

      - name: Deploy to GitHub Pages
        uses: peaceiris/actions-gh-pages@v3
        with:
          github_token: ${{ secrets.GITHUB_TOKEN }}
          publish_dir: ./api
```

## 8. 通知功能

### 通知邏輯
- **觸發時機**：processor 產出 `upcoming.json` 時
- **篩選條件**：除權息日在 3 天內的證券
- **推播內容**：配息提醒訊息

### 通知範例
```
📢 配息提醒

以下證券即將除權息：

• 0056 元大高股息
  除權息日：2026-07-20
  配息金額：$1.80

• 2330 台積電
  除權息日：2026-07-25
  配息金額：$3.50
```

## 10. 風險登錄

| 風險 | 可能性 | 影響 | 緩解措施 |
|------|--------|------|---------|
| TWSE 改版導致爬蟲失效 | 中 | 中 | 監控爬蟲成功率，失敗時手動檢查 |
| GitHub Actions 限時 6 分鐘 | 低 | 低 | 資料量不大，通常 1-2 分鐘完成 |
| LINE Notify 政策變動 | 低 | 中 | 備案：Email 通知 |
| GitHub Pages 快取問題 | 低 | 低 | 檔名加時間戳記（cache busting） |
